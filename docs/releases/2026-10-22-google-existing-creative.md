# Google asset sources and CLX catalog visibility

Existing Google campaigns now use the shared Activation Studio flow: account and campaign, ad group or asset group, compatible format tiles, assets, and review. Performance Max additions can combine images, videos and text while preserving the selected campaign/group and existing assets. Display, Demand Gen, Search and App expose their implemented formats; this release does not implement additional Demand Gen video ad types.

The source picker offers EvokeLoop Library, inline Upload, and Google Ads Library. Approved assets have searchable, paginated preview tiles and a selected-assets tray. Google assets are filtered by media type; browsing shows the latest 200 account assets. YouTube links and IDs are also accepted. Upload uses the existing file preview and approval controls (12 MB images, 20 MB videos).

Approved library videos can be transferred through Google Ads' native resumable upload API to an unlisted Google-managed YouTube channel. This requires a separate explicit confirmation and publisher/admin/owner access. Upload status survives returning to the page, processing is polled, and uncertain results are never retried automatically. The processed video is added to the draft only on request; publishing still follows the existing final review. LIVE_AD_ACTIONS_ENABLED gates remote uploads. No actual customer video was uploaded during verification.

The CLX API import is present. The reported model has a separate website-imported approved record with FPS benchmarks and an API record with 17 hardware specifications pending review. Product details now identify the selected source, show exact-identity matches from other catalog sources, preview their specs and link to a filtered catalog review. Pending facts cannot be selected for generation. The refresh comparison now ignores object-key ordering, preventing unchanged JSONB specifications from being marked as changed and invalidating approval again. Existing pending records still require catalog review; this release does not silently approve or merge products.

No migration or dependency change is required. Verification covers six campaign creation families, existing mixed-media PMax additions and saved payloads, source filtering, inline uploads, explicit video confirmation, upload permissions, stale revisions, uncertain outcomes, provider session validation, catalog identity and unchanged refresh behavior. Chrome fixtures cover existing-campaign format/source tiles, inline upload and Google asset previews at desktop/mobile widths. Full CI gates merge and deployment.

This addresses the existing-campaign creative selection and source gaps in #83; remaining advanced Google campaign capabilities are outside this release.
