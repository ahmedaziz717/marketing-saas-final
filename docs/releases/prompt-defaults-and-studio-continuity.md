Review scope; deployment is not authorized. Base release: dead219d835f99d42a9c99efe0fc5b39a881253b.

## Prompt coverage

The authoritative catalog is `shared/promptRegistry.ts`; protected instruction contracts are in `shared/promptContracts.ts`. Settings → Prompt defaults shows the resolved workspace value, immutable baseline, and latest 100 revisions. Owners/admins can save with a reason, restore the system baseline, or restore a historical workspace revision. Members can read. Restoration appends history. Existing user-authored prompts and saved workflow/App versions remain explicit content, not defaults to rewrite.

Image/video assembly still contains deterministic interpolation and preservation/identity/typography/provider instructions. These enforce selected options and output contracts; they are not independently editable workspace business guidance. Provider-internal hidden instructions, credentials and security policy are not exposed. Structured schema and factual/safety rules cannot be overridden through the registry.

Resolution is frozen within each AI operation and refreshed for the next operation. Used prompt IDs, baseline versions, workspace revisions and source are recorded in AI usage provenance. A multi-step workflow can resolve a newer default in a later operation; it is not a whole-run snapshot. UI saves invalidate the workspace query and notify other tabs; refetch never silently replaces unsaved editor text. Optimistic revisions reject stale saves. Local migration 0020 creates the tenant-scoped append-only table with RLS; no production migration has been applied.

## Brand summary and provider budget

Long brand voices are semantically summarized into identity, audience, tone, messaging priorities, do rules, don't rules and constraints. The source guide is never overwritten. A workspace-scoped content hash includes source, policies, model, summary version and resolved summary template. The private asset store caches the structured result; in-process requests coalesce. Invalid/incomplete summaries and storage outages fail clearly rather than sending an oversized original or repeatedly buying summaries. Summaries are included in the generation action, not a separate user-credit charge. Provider-specific final character limits are checked before image uploads/reservations. Explicit user content is not blindly truncated. Tests use mocked models and storage; no paid generation was retried.

## Studio continuity and entity rules

| Surface               | Remembered setup                                                                                             | Entity / reset behavior                                                                                                                                                            |
| --------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Creative image/video  | Full configurator setup including source, name, URL/category, look/feel, story/sound, model, output, toggles | User/workspace/type/entity keys; saved video revision check; explicit saved-draft load wins; unavailable references remain subject to validation; no scrape/generation on restore. |
| Insights              | Report config, selected account/channel/options                                                              | Saved entity revision check; live refetch does not replace edits.                                                                                                                  |
| Optimization          | Config, account/cohort/dates/focus/model/options                                                             | Saved entity revision check; no analysis on restore.                                                                                                                               |
| Activation publishing | Channel, destination, content, assets, schedule/timezone/options                                             | Publication entity/revision scoped; current setup reset only.                                                                                                                      |
| Activation Google     | Account, campaign mode, format, assets/copy/delivery choices                                                 | Same saved revision restores local edits; newer server revision wins with notice; missing saved entity blocks submission and preserves local cache. Approval is never restored.    |

Drafts are local to this browser/device, scoped by user and workspace, capped at 500 KB, and validated before use. A blocked storage API does not crash the app. Unfinished values are retained without weakening submit validation. Reset requires confirmation and affects current setup only, not central prompt definitions, saved entities, other studios or live campaigns. No restore/reset auto-submits. File objects are not persisted; stored asset/reference identifiers are revalidated by existing availability checks.

## Validation

- Focused in-memory PostgreSQL tests cover tenant/role isolation, protected contracts, optimistic conflicts, history restore and per-operation provenance.
- Mocked summary tests cover caching, changed source/template keys, coalescing, malformed/incomplete summaries and storage failure. Budget tests verify rejection before provider work.
- Studio component tests cover user/workspace isolation, stale entity revisions, missing entities, unfinished drafts, explicit saved-draft load and reset.
- `scripts/check-studio-persistence.mjs` uses actual components with synthetic data in isolated Chrome: desktop/mobile × light/dark, another Studio, Back/Forward, refresh, cancel/confirm Reset, and zero submissions.
- CI runs PostgreSQL migrations, typecheck, full tests, build/smoke and browser matrices. The PR must pass those checks before release readiness; no production values are used for tests.
