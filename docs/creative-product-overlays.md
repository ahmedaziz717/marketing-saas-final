# Complete creative designs and original product layers

Generation uses the full creative prompt, selected theme/mood/art style, all product/campaign/logo references, copy and font direction. It does not generate an empty scene or rasterize a fixed text card. Font preservation is off by default; the picker includes Rubik and other sans, display, serif, script and monospaced families. These direct generated typography rather than promising exact typesetting.

Enabling Preserve original product checks transparent cutouts before charging. The complete generated creative is saved unchanged with `editable_original_v3` metadata. **Adjust original product** opens the separate placement editor in Studio or Asset Library. A metered **Suggest alignment** request measures product bounds in the complete design; manual drag, proportional size, horizontal/vertical controls and comparison opacity support corrections. The source angle and aspect ratio remain unchanged. Different 3D viewpoints cannot be recovered from a single cutout, and mismatched angles are flagged.

Saving composites the original source pixels onto the immutable design and creates a new pending-review variant. It never changes the original image or carries approval forward. Every subsequent edit starts from the saved base design, avoiding accumulated overlays. Membership, variant scope, revision and original-source digest are checked. No AI pass runs after compositing. The user must inspect alignment: transparency or shape differences can expose generated pixels around a source, and placement is not a guarantee of segmentation or occlusion recovery.

Logos can be uploaded directly in the builder or company settings. Shared Google Drive file/folder links can discover direct PNG/JPG/WebP/GIF/SVG files for selection, up to 50 candidates and 20 imports at once. Nested/private folders are not scanned. Downloads are bounded, DNS-pinned and restricted to Google file hosts; bytes are checked and SVG external references rejected before rasterization. Imported logos require the existing review/approval workflow before use.
