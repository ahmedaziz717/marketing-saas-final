# Art Style Influence

Subtle, Balanced and Strong are shared prompt-direction levels, not provider percentages or image quality settings. The selected visual medium takes precedence over conflicting photographic scene wording in editable defaults. Product identity, physical geometry, colors, markings, facts, selected copy, preserved fonts/logos and person identity remain protected. Strong Animation specifically styles the non-product environment; preserved original product photos are not redrawn.

The optional artStyleInfluence property is stored with image setup and video direction. Old saved setups remain valid and are not migrated or rewritten; omitted values use Balanced when composing a new generation prompt. Workspace defaults are never mutated. Ordinary Enhance keeps its source styling and disables this control with an explanation. It is not a restyling action.

Studio, legacy image/video forms and workflow video direction use the same control. Workflow designers can add the built-in Art Style Influence field and connect it to generation along with an Art style field. Published App forms use the existing shared choice renderer and emit the same prompt policy. Existing published workflow snapshots are not changed.

No provider style_strength parameter is invented. Different models can interpret the same directions differently, and generation outcomes still need review.
