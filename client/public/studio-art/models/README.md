# Model covers

Dedicated AI-generated editorial covers for the Creative Studio model picker.
These are visual identities, not output samples from the named models or official
maker logos. They are separate from theme and art-style imagery.

18 original approved covers are served as 900px WebP images. Related model
variants share family artwork. Generic image routes use the GPT Image cover;
generic cinematic routes use the Kling cover, and Genjutsu uses the fantasy
landscape cover. Route-based mapping lives in `studioArtwork.ts` so a change in
display name or catalog order does not randomly change the picture.

Art direction: central compositions with distinct subjects and palettes: amber
glass sunburst, coral flare, emerald sculpture, miniature peach cube, campaign
panels, graphic ribbons, editorial portrait, cosmic glass, dimensional letter
forms, origami dragon, metallic lightning, dancer, cinematic car, glass wave,
fantasy landscape, light tunnel, white horse, and astronaut.
