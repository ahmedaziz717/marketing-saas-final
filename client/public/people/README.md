# Lifestyle portrait library

100 fictional AI-generated adult casting references, created with the built-in image generation tool for Frame. Five hair groups for each gender, ten portraits per sheet. PNG masters remain outside the repository; these WebP delivery copies preserve the source composition.

Prompt template: One photorealistic casting contact sheet. Exactly ten distinct fictional adult women/men with BLACK, BROWN, BLONDE, RED/AUBURN, or GRAY/SILVER hair, ages 25–60, diverse skin tones, face shapes and hairstyles. Exactly five equal columns and two equal rows, edge-to-edge portraits, no gutters, labels, text, or watermark. Centered head and shoulders, neutral light gray studio background, modest solid shirts, natural expressions and realistic skin. Landscape 5:2.

Files use stable names: `{female|male}-{black|brown|blonde|auburn|silver}.webp`. Do not replace existing identities: new editions require new IDs and filenames so saved drafts remain consistent. Browser tile previews and generation-time reference extraction use the same five-column, two-row coordinates in shared/lifestylePeople.ts. Final image requests receive only the selected portrait, never the full contact sheet. Public library presets contain no customer uploads; uploaded and saved Brand references use private workspace storage.
